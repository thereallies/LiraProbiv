# OSINT-MAX Bot

Бот с монетизацией, подписками, поиском по username, email, телефону, ссылкам, фото, ИНН, утечкам HIBP.

## Деплой на Bothost.ru

1. Создайте репозиторий на GitHub и загрузите все файлы.
2. Зайдите на bothost.ru, создайте бота, выберите "Из Git".
3. Вставьте URL вашего репозитория.
4. В разделе "Переменные окружения" добавьте все ключи из `.env.example`.
5. Нажмите "Развернуть".
6. Выполните SQL-скрипт `supabase.sql` в вашем Supabase.
7. Бот запустится автоматически.

## Админ-команды
- `/add_balance 123456 100` – пополнить баланс
- `/stats` – статистика
